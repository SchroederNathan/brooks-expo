# @demo/catalog

The shared data layer for the app.

- `catalog.json` — a synthetic product catalog: 226 products, 821 colourways,
  generated by `tools/debrand` from a harvested snapshot. Product families,
  descriptions, colourway names, and reviews are all invented; see
  `tools/debrand/names.js` for exactly what was replaced.
- `reviews.json` — generated reviews for every catalog product. Ratings and
  fit-dimension averages are real numbers from the harvest; titles, bodies, and
  authors are synthetic (`tools/debrand/reviews.js`).
- `constructor.ts` — on-device search over `catalog.json`. This used to be a
  live client for a real retailer's search index; nothing leaves the device now.
- `images.ts` — swatch helpers. The catalog carries no photography, so each
  colourway stores the colours it names and the app draws them.
- `query.ts`, `types.ts` — filtering, sorting, faceting, and the schema.

This package is the source of truth. `bun run sync` copies it into `assets/`
and `src/data/`; edit the package, not the copies.
